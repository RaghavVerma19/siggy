Everything you need to remember

Siggy combines vector memory, knowledge graphs, and operational experience
into a single retrieval pipeline.

Vector Memory

Retrieves similar past incidents from Qdrant vector search across your entire operational history.

Knowledge Graph

Expands context through services, components, failure types, and their operational relationships.

Experience Engine

Ranks fixes using historical success rates, resolution times, and engineer feedback.

Auto-Instrumentation

Wraps any Python app with OpenTelemetry. Zero code changes. One command.

Explainable Recommendations

Returns root cause, fix, confidence, and evidence — not just a text answer.

Graceful Degradation

Works without external LLMs, without Qdrant Docker, without a SigNoz API key.

How Siggy works

Six steps from telemetry to explainable recommendation.

Telemetry

Your app sends traces to SigNoz

→
Normalize

Incident becomes a structured KnowledgeObject

→
Retrieve

Vector search finds similar past incidents

→
Expand

Graph adds related services and patterns

→
Rank

Experience engine scores by historical outcomes

→
Recommend

Explainable fix returned to SigNoz

Engineers record outcomes. Future recommendations improve.

Nine commands. One sidecar.

A CLI that works like a senior SRE sitting next to you.


        


        

          

            siggy init
            Connect to SigNoz, configure memory
          

          

            siggy quickstart
            One-command setup, auto-detects everything
          

          

            siggy instrument
            Auto-instrument any Python app with OTel
          

          

            siggy watch
            Sidecar mode, enriches alerts with memory
          

          

            siggy serve
            Start API server + sidecar
          

          

            siggy up
            All-in-one: server + sidecar + your app
          

          

            siggy investigate
            Manual investigation through memory pipeline
          

          

            siggy status
            System health and connection checks
          

          

            siggy demo
            Ready-to-go demo, no SigNoz needed
